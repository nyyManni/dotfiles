# ECA

Only personal instructions, rules, and the `create-ai-knowledge-base` and
`windows-vm-dev` skills are tracked. Link individual files into `~/.config/eca`
or Stow into the existing directory.

Keep `config.json` local: it contains provider/MCP settings and authentication
references. The other skills are managed externally, including two independent
Git checkouts; their repositories and history are deliberately not imported.
